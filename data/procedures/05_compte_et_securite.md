# Compte client et sécurité

## Mot de passe oublié
Depuis la page de connexion, le lien « Mot de passe oublié » envoie un e-mail de réinitialisation à l'adresse du compte. Le lien est valable 30 minutes. Le nouveau mot de passe doit comporter au moins 10 caractères, dont un chiffre.

## Compte bloqué
Après 3 tentatives de connexion erronées, le compte est bloqué pendant 24 heures. Le client peut le débloquer immédiatement avec le bouton « Débloquer mon compte » : un code est alors envoyé par SMS au numéro enregistré.

## Vérification en deux étapes
La vérification en deux étapes envoie un code à 6 chiffres par SMS à chaque connexion depuis un nouvel appareil. Le code est valable 5 minutes. Un code expiré doit être redemandé avec le bouton « Renvoyer un code » ; au-delà de 5 demandes en une heure, l'envoi est suspendu pendant une heure.

## Changer de numéro de téléphone
Le numéro qui reçoit les codes de sécurité se modifie dans l'espace client, rubrique Sécurité. Pour protéger le compte, l'ancien numéro reçoit un code de confirmation. Si l'ancien numéro n'est plus accessible, le client doit se présenter en boutique avec une pièce d'identité.

## Connexion inhabituelle
Une alerte est envoyée lorsqu'une connexion a lieu depuis un appareil ou un pays inhabituel. Si le client ne reconnaît pas cette connexion, il clique sur « Ce n'était pas moi » : toutes les sessions sont fermées et le mot de passe doit être changé.
